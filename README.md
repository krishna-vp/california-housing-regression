# California Housing Regression Assignment
* This project demonstrate regression techniques using the California Housing dataset from sklearn.

## Algorithms Used
1. Linear Regression
2. Decision Tree Regressor
3. Random forest Regressor
4. Gradient Boosting Regressor
5. Support Vector Regressor (SVR)

## Evaluation Metrics
1. Mean Squared Error (MSE)
2. Mean Absolute Error (MAE)
3. R2 (R-Square) Score

## Tools and Libraries
1. Python
2. Jupyter Notebook
3. Pnadas
4. Numpy
5. Scikit-learn

## Dataset
California Housing Dataset from sklearn.
